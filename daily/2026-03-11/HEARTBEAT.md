### 5. 日报自动生成

**基本信息**
- **任务ID**: `a1b2c3d4-e5f6-7890-abcd-ef1234567890`
- **描述**: 每日16:00(北京时间)自动生成个人日报，非节假日执行
- **Cron表达式**: `0 8 * * *`
- **时区**: `Asia/Shanghai`
- **状态**: 启用
- **执行模式**: isolated

**执行内容**
```
执行日报生成脚本：bash ~/.openclaw/scripts/daily-report.sh
```

**脚本位置**: `~/.openclaw/scripts/daily-report.sh`

**节假日判断逻辑**:
1. 查询 http://api.nager.date/v3/holiday/2026/CN 获取中国法定节假日
2. 判断逻辑：
   - 今日是法定节假日 → 不生成，结束
   - 今日是调休工作日（周末却被标记为工作日）→ 生成日报
   - 正常周一到周五 → 生成日报
   - 周末（非调休工作日）→ 不生成
3. 需生成时调用 Python 脚本生成日报
4. Python脚本自动完成：保存本地文件 + 创建飞书云文档 + 授予权限

**通知配置**
- 模式: announce
- 渠道: feishu
- 目标: user:ou_74a621752a07aed1c6db1b765365d15a
