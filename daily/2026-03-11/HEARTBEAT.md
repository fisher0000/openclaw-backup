## 使用说明

### 启动专业Agent任务：

```
@PM-Agent 启动新项目评估，项目：XXX原料药开发
@CMC-Agent 设计合成路线，目标分子：XXX
@CTD-Agent 准备DMF申报资料
@QC-Agent 开发有关物质分析方法
@QA-Agent 进行GMP合规审计
```

### 启动完整工作流：

```
启动原料药CMC开发工作流，项目：XXX
```
