## ⏰ 每日任务清单

### 09:00 - AI科技情报日报

**任务描述：** 检查过去24小时AI领域重大资讯

**执行内容：**
- [ ] 扫描P0必报项：大模型突破、AI安全政策、头部公司战略、算力供应链
- [ ] 生成 Executive Briefing 格式报告
- [ ] 标注对虾总业务的影响矩阵（威胁/机会/工具）

**输出模板：**
```
📮 AI情报日报 [日期]
━━━━━━━━━━━━━━━━━━
🚨 头条警报：[最高优先级1条，50字内核心结论]
📈 技术趋势：[3条深度分析]
💰 资本动态：[2条投融资解读]
🎯 今日建议：[针对虾总业务的具体行动项]
📌 待关注：[设置明日监测关键词]
```

## 🔧 技术运维任务

### 每周权限健康检查（每周一 10:00）

**任务描述：** 基于飞书API权限知识库，检查系统权限状态

**执行内容：**
- [ ] 检查当前飞书应用权限使用情况
- [ ] 对照 `permission_kb.json` 数据库，识别：
  - 是否申请了不必要的权限（权限最小化原则）
  - 是否缺少关键权限导致功能受限
  - 高级权限的使用是否符合安全规范
- [ ] 生成权限审计报告

**输出模板：**
```
🔐 权限健康检查报告 [日期]
━━━━━━━━━━━━━━━━━━
✅ 正常权限：[列表]
⚠️ 待优化：[冗余权限/权限过大建议]
❌ 缺失权限：[影响功能的权限缺口]
📋 建议操作：[具体改进建议]
```
