### 2. Obsidian-Git 冲突问题

**错误**：
```
Pull failed (merge): error: Your local changes to the 
following files would be overwritten by merge:
  .obsidian/community-plugins.json
```

**原因**：本地修改未提交，Git 不允许直接拉取。

**解决方案**：
1. 先 Commit 本地更改
2. 再 Pull 远程
3. 最后 Push（如需要）

**预防建议**：
- 开启 Auto commit interval（5 分钟）
- 养成"修改 → Commit → Pull → Push"习惯

---
